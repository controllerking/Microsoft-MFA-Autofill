Microsoft MFA TOTP Autofill

Every TOTP secret is encrypted with a key derived from your passphrase (PBKDF2 + AES-GCM) before it touches disk. The passphrase itself is never stored, and the decryption key only ever lives in the background script's memory for your current browser session — pages you visit and the popup never see raw secrets.

Create a vault passphrase
There is no password recovery. If you forget this passphrase, the only option is to reset the vault, which permanently deletes every stored account and secret.

I don't want a passphrase (not recommended)

Without a passphrase, TOTP secrets are stored unencrypted in your browser profile. Anyone with access to this device's files (or malware running as you) could read them. Only choose this if you understand and accept that risk.
